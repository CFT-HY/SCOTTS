# Policy on AI contributions and training

SCOTTS is a code written by a team of humans to understand and solve a problem posed by humans, with the satisfaction that only comes from understanding what we have done and why. This policy is not set in stone, and will likely evolve as the use of generative AI develops, but represents the current policy applicable to SCOTTS as of August 2026:

- Content, code and commits generated entirely by AI are not permitted under any circumstances.
- If you commit code or other content to this repository, you are affirming that you are the sole author of the code, that you hold the copyright, and that you are permitted to license the code under the MIT license. This is not really possible if the code was developed by a large language model.
- You should be able to explain the coding choices and physics behind any line of code you commit.

If you follow the above guidelines, the other developers of SCOTTS should be unable to tell that you have used agentic AI unless you inform us. Therefore, if you use agentic AI to help you in your code development that is fine so long as the final code is your own (like discussing a homework problem with friends but writing it up yourself). However we would rather you are open about what tools you use than that you try to hide things from us. An open dialogue about the use of agentic AI will help us to reflect on this policy.

## Training on SCOTTS

In line with the MIT license, if your model produces code or content recognisably attributable to the SCOTTS code, you **must** reproduce the copyright notice associated with the repository. While the authors cannot prevent the repository from being used as training data, based on our concerns around copyright attribution, we would prefer that it not be used.

## Note

This policy was agreed by all the contributors to the SCOTTS repo as of August 2026.
